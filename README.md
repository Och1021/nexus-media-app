# Nexus Media — компьютерийн апп (Windows, Mac)

Апп нь https://nexus-media-d4b46.web.app сайтыг цонхондоо ачаалдаг Electron апп. Тиймээс сайтад гарсан өөрчлөлт (чат, төсөл, дизайн) апп дээр шууд харагдана, апп дахин гаргах шаардлагагүй.

## Боломжууд
- Сайтын бүх боломж, Google-ээр нэвтрэх, админ эрх
- Админтай бодит цагийн чат, шинэ мессежийн мэдэгдэл, дуу, taskbar/Dock дээрх тэмдэг
- Интернэт тасарвал тусгай хуудас гарч, холболт сэргэхэд өөрөө дахин ачаална
- Цонхны хэмжээ, байрлалыг санана
- **Автомат шинэчлэлт** (GitHub Releases-ээс):
  - Windows: шинэ хувилбарыг ард нь татаж, «Одоо шинэчлэх» гэж асууна (эсвэл дараагийн удаа хаахад шинэчлэгдэнэ)
  - Mac: Apple гэрчилгээгүй тул шинэ хувилбар гарахад «Татах» товчтой цонх гарна

## Шинэ хувилбар гаргах
1. Өөрчлөлтөө commit хийнэ.
2. Шинэ tag push хийнэ: `git tag v1.0.1 && git push origin v1.0.1`
3. GitHub Actions Windows, Mac хувилбаруудыг бүтээж Releases-д нийтэлнэ (≈10–15 мин).
4. Суусан аппууд 4 цаг тутам (мөн нээх бүрд) шинэчлэлт шалгаж, өөрөө шинэчлэгдэнэ.

Хувилбарын дугаарыг tag-аас авдаг (package.json-ийн version-ийг гараар өөрчлөх шаардлагагүй).

## Компьютер дээрээ турших (Windows)
`build-windows.bat`-ыг давхар товшвол `dist\NexusMedia-Setup.exe` гарна.

## Файлууд
- `main.js` — цонх, нэвтрэх цонх, гадны холбоос, мэдэгдэл, автомат шинэчлэлт
- `preload.js` — сайтад `window.nexusApp` (тэмдэг, анхааруулга) өгнө
- `offline.html` — интернэтгүй үеийн хуудас
- `.github/workflows/build.yml` — Windows + Mac бүтээх, нийтлэх
